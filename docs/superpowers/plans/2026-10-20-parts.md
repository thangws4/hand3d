# Tách mô hình thành linh kiện — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trong `/play`, xoè 2 tay để bung/ráp linh kiện, chụm trên một linh kiện để cầm nó ra; robot mẫu nhiều linh kiện thay khối lập phương làm model mặc định.

**Architecture:** Logic thuần mở rộng `Controller` (độ bung, offset từng linh kiện, cầm/thả, con trỏ) với `hitTest(x, y)` tiêm vào; `lib/parts.ts` tính offset bung; `lib/demoModel.ts` là dữ liệu robot. `Scene` tách model thành linh kiện (mỗi `Mesh` một linh kiện), áp offset mỗi khung, cung cấp `hitTest` bằng raycast và làm sáng linh kiện. `Player` hiện con trỏ, tên linh kiện, ghi chú model liền khối.

**Tech Stack:** Next.js 16, React 19, three 0.186, @react-three/fiber 9, Node 22 test runner.

**Spec:** `docs/superpowers/specs/2026-10-20-parts-design.md`

## Global Constraints

- `web/lib/*.ts` chạy được bằng Node type stripping: không enum/namespace/parameter properties; import tương đối ghi đuôi `.ts`; `npm test` = `node --test "lib/**/*.test.ts"`.
- Hằng số mới: `EXPLODE_SENS = 3`, `EXPLODE_MAX = 1.5`. Khoảng cách 2 tay khi bung đo giữa landmark 9 của hai tay.
- Ưu tiên cử chỉ: FIST > 2 PINCH > 2 OPEN > THUMBS_UP (cộng dồn) > kéo 1 tay (PINCH bắt đầu trên linh kiện = cầm; còn lại như cũ).
- Con trỏ = landmark 8 của `hands[0]` (đã lật gương), toạ độ chuẩn hoá 0..1 của khung 3D.
- Offset cầm lưu theo mặt phẳng màn hình (đơn vị world, `PAN_SENS`); Scene quy đổi sang hệ toạ độ của linh kiện.
- Model có ≤ 1 mesh: `hitTest` luôn trả `null` (không cầm được), HUD ghi "liền một khối, không tách được linh kiện".
- Chữ hiển thị tiếng Việt có dấu. Bản Python không đổi.

## Review Focus

- Hai tay đang xoè, một tay bị nhận nhầm 1 khung rồi xoè lại ở khoảng cách khác → độ bung không được nhảy (test ở Task 2).
- Đang cầm linh kiện thì tay thứ hai chụm (zoom 2 tay) → thả linh kiện, không kéo tiếp (test ở Task 2).
- Thả lại đúng file .glb đã dùng (useGLTF trả scene đã cache, mesh đã bị dịch) → linh kiện phải về đúng chỗ cũ, không lệch sẵn: collector khôi phục vị trí gốc khi unmount (kiểm tra thủ công ở Task 3).
- Model đang xoay 180° mà kéo linh kiện sang phải → linh kiện đi sang phải trên màn hình (quy đổi trong Scene; người dùng thử tay thật).
- glb dùng chung một material cho nhiều mesh → làm sáng một linh kiện không được sáng lây: collector clone material từng mesh (kiểm tra thủ công ở Task 3).

```ts
import { classify, dist, Smooth, type Gesture, type Landmark } from "./gestures.ts";
import type { Vec2 } from "./parts.ts";

export const ROT_SENS = 300; // độ xoay khi tay quét hết chiều ngang khung hình
export const PAN_SENS = 20; // đơn vị dịch chuyển khi tay quét hết khung hình
export const ZOOM_SENS = 3; // chữ V: kéo lên 1/10 khung hình → to thêm ~30%
export const SPIN_SPEED = 90; // độ/giây khi giơ ngón cái
export const ZOOM_MIN = 0.2, ZOOM_MAX = 5;
export const EXPLODE_SENS = 3; // xoè 2 tay: kéo xa thêm 1/10 khung hình → bung thêm 0.3
export const EXPLODE_MAX = 1.5;
export const MAX_DT = 0.1; // tab bị ẩn rồi mở lại: không cho dt lớn làm model quay vọt
const DRAG_GESTURES: Gesture[] = ["PINCH", "POINT", "PEACE"];

export type Hand = { landmarks: Landmark[]; side: "Left" | "Right" };
/** Góc tính bằng độ (quy ước Ursina); zoom tương đối, 1 = vừa khung; partOffsets theo mặt phẳng màn hình (đơn vị world). */
export type Transform = {
  rotX: number;
  rotY: number;
  x: number;
  y: number;
  zoom: number;
  explode: number;
  partOffsets: Record<string, Vec2>;
};
/** Linh kiện nằm dưới điểm (x, y) chuẩn hoá của khung 3D, hoặc null. */
export type HitTest = (x: number, y: number) => string | null;

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));
const initial = (): Transform => ({ rotX: 0, rotY: 0, x: 0, y: 0, zoom: 1, explode: 0, partOffsets: {} });
```

Thay toàn bộ `class Controller` bằng:
```ts
export class Controller {
  transform: Transform = initial();
  cursor: Vec2 | null = null; // đầu ngón trỏ tay đầu tiên
  hovered: string | null = null; // linh kiện dưới con trỏ
  grabbed: string | null = null; // linh kiện đang cầm
  #drag: { gesture: Gesture; x: number; y: number } | null = null; // vị trí khung trước
  #zoomStart: { d0: number; z0: number } | null = null; // lúc bắt đầu zoom 2 tay
  #explodeStart: { d0: number; e0: number } | null = null; // lúc bắt đầu xoè 2 tay
  #smoothX = new Smooth();
  #smoothY = new Smooth();

  reset(): void {
    this.transform = initial();
    this.grabbed = null;
    this.#drag = null;
    this.#zoomStart = null;
    this.#explodeStart = null;
  }

  step(hands: Hand[], dt: number, hitTest: HitTest = () => null): Gesture[] {
    dt = Math.min(dt, MAX_DT);
    const gestures = hands.map((h) => classify(h.landmarks));
    const tip0 = hands[0]?.landmarks[8];
    this.cursor = tip0 ? { x: tip0.x, y: tip0.y } : null;
    this.hovered = this.cursor ? hitTest(this.cursor.x, this.cursor.y) : null;
    const pinches = hands.filter((_, i) => gestures[i] === "PINCH");
    const opens = hands.filter((_, i) => gestures[i] === "OPEN");
    const t = this.transform;

    if (gestures.includes("FIST")) {
      this.reset();
      return gestures;
    }
    if (pinches.length === 2) {
      this.#drag = null;
      this.grabbed = null;
      this.#explodeStart = null;
      const d = dist(pinches[0].landmarks[8], pinches[1].landmarks[8]);
      this.#zoomStart ??= { d0: Math.max(d, 1e-6), z0: t.zoom };
      t.zoom = clamp((this.#zoomStart.z0 * d) / this.#zoomStart.d0, ZOOM_MIN, ZOOM_MAX);
      return gestures;
    }
    this.#zoomStart = null;
    if (opens.length === 2) {
      this.#drag = null;
      this.grabbed = null;
      const d = dist(opens[0].landmarks[9], opens[1].landmarks[9]);
      this.#explodeStart ??= { d0: d, e0: t.explode };
      t.explode = clamp(this.#explodeStart.e0 + (d - this.#explodeStart.d0) * EXPLODE_SENS, 0, EXPLODE_MAX);
      return gestures;
    }
    this.#explodeStart = null;
    if (gestures.includes("THUMBS_UP")) t.rotY += SPIN_SPEED * dt;

    const i = gestures.findIndex((g) => DRAG_GESTURES.includes(g));
    if (i < 0) {
      this.#drag = null; // thả tay: "nhả ly hợp", model đứng yên
      this.grabbed = null;
      return gestures;
    }
    const g = gestures[i];
    const tip = hands[i].landmarks[8];
    let prev = this.#drag;
    if (!prev || prev.gesture !== g) {
      // vừa đổi cử chỉ: xoá lịch sử lọc để không bị giật; chụm bắt đầu trên linh kiện = cầm nó
      this.#smoothX.reset();
      this.#smoothY.reset();
      prev = null;
      this.grabbed = g === "PINCH" ? this.hovered : null;
    }
    const x = this.#smoothX.next(tip.x);
    const y = this.#smoothY.next(tip.y);
    if (prev) {
      const dx = x - prev.x, dy = y - prev.y;
      if (g === "PINCH" && this.grabbed) {
        const o = t.partOffsets[this.grabbed] ?? { x: 0, y: 0 };
        t.partOffsets[this.grabbed] = { x: o.x + dx * PAN_SENS, y: o.y - dy * PAN_SENS };
      } else if (g === "PINCH") {
        t.rotY -= dx * ROT_SENS;
        t.rotX -= dy * ROT_SENS;
      } else if (g === "POINT") {
        t.x += dx * PAN_SENS;
        t.y -= dy * PAN_SENS; // ảnh: y tăng xuống dưới; 3D: y tăng lên trên
      } else {
        t.zoom = clamp(t.zoom * (1 - dy * ZOOM_SENS), ZOOM_MIN, ZOOM_MAX); // PEACE: kéo lên = phóng to
      }
    }
```

```tsx
"use client";
import { useGLTF } from "@react-three/drei";
import { Canvas, useFrame, useThree } from "@react-three/fiber";
import { Component, memo, Suspense, useCallback, useLayoutEffect, useMemo, useRef, type ReactNode, type RefObject } from "react";
import * as THREE from "three";
import type { HitTest, Transform } from "@/lib/controller";
import { DEMO_PARTS, type DemoPart } from "@/lib/demoModel";
import { fitScale } from "@/lib/model";
import { explodeOffset } from "@/lib/parts";

export type PartSummary = { id: string; name: string };
export type FrameFn = (dt: number, hitTest: HitTest) => { transform: Transform; highlight: string | null };

type PartInfo = PartSummary & {
  mesh: THREE.Mesh;
  root: THREE.Object3D;
  base: THREE.Vector3; // vị trí gốc của mesh (trong hệ của parent)
  center: THREE.Vector3; // tâm linh kiện, hệ toạ độ root
  modelCenter: THREE.Vector3; // tâm cả model, hệ toạ độ root
};

function PartGeometry({ part }: { part: DemoPart }) {
  const [a, b, c] = part.size;
  if (part.shape === "box") return <boxGeometry args={[a, b, c]} />;
  if (part.shape === "sphere") return <sphereGeometry args={[a, 24, 16]} />;
  return <cylinderGeometry args={[a, c, b, 24]} />;
}

/** Robot mẫu: mỗi khối là một mesh có tên → một linh kiện. */
function DemoRobot() {
  return (
    <group>
      {DEMO_PARTS.map((p) => (
        <mesh key={p.id} name={p.name} position={p.position}>
          <PartGeometry part={p} />
          <meshStandardMaterial color={p.color} roughness={0.5} />
        </mesh>
      ))}
    </group>
  );
}

/** Model tải về có thể to/nhỏ/lệch tâm bất kỳ → đưa về giữa và co giãn cho vừa. */
export function GltfModel({ url }: { url: string }) {
  const { scene } = useGLTF(url);
  const { offset, scale } = useMemo(() => {
    const box = new THREE.Box3().setFromObject(scene);
    return {
      offset: box.getCenter(new THREE.Vector3()).negate(),
      scale: fitScale(box.getSize(new THREE.Vector3())),
    };
  }, [scene]);
  return (
    <group scale={scale}>
      <primitive object={scene} position={offset} />
    </group>
  );
}

type BoundaryProps = { onError: (e: Error) => void; children: ReactNode };
/** glb hỏng → báo lỗi và hiện robot mẫu thay vì làm trắng trang. */
export class ModelBoundary extends Component<BoundaryProps, { failed: boolean }> {
  state = { failed: false };
  static getDerivedStateFromError() {
    return { failed: true };
  }
  componentDidCatch(e: Error) {
    this.props.onError(e);
  }
  render() {
    return this.state.failed ? <DemoRobot /> : this.props.children;
  }
}

const materialsOf = (mesh: THREE.Mesh) => (Array.isArray(mesh.material) ? mesh.material : [mesh.material]);

function setHighlight(mesh: THREE.Mesh, on: boolean) {
  for (const m of materialsOf(mesh)) {
    if (!("emissive" in m)) continue;
    const e = (m as THREE.MeshStandardMaterial).emissive;
    e.copy(on ? new THREE.Color("#1f6f5c") : (m.userData.baseEmissive as THREE.Color));
  }
}

/** Mỗi Mesh trong model là một linh kiện. Clone material để làm sáng một linh kiện không lây sang mesh dùng chung material. */
function collectParts(root: THREE.Object3D): PartInfo[] {
  root.updateMatrixWorld(true);
  const meshes: THREE.Mesh[] = [];
  root.traverse((o) => {
    if ((o as THREE.Mesh).isMesh) meshes.push(o as THREE.Mesh);
  });
  const centerInRoot = (o: THREE.Object3D) => root.worldToLocal(new THREE.Box3().setFromObject(o).getCenter(new THREE.Vector3()));
  const modelCenter = centerInRoot(root);
  return meshes.map((mesh, i) => {
    mesh.material = Array.isArray(mesh.material) ? mesh.material.map((m) => m.clone()) : mesh.material.clone();
    for (const m of materialsOf(mesh)) {
      if ("emissive" in m) m.userData.baseEmissive = (m as THREE.MeshStandardMaterial).emissive.clone();
    }
    return { id: mesh.uuid, name: mesh.name || `Linh kiện ${i + 1}`, mesh, root, base: mesh.position.clone(), center: centerInRoot(mesh), modelCenter };
  });
}

/** Chạy sau khi model trong cùng Suspense đã sẵn sàng; khi unmount trả mesh về chỗ cũ (scene glb được cache và dùng lại). */
function PartsCollector({ rootRef, partsRef, onParts }: {
  rootRef: RefObject<THREE.Group | null>;
  partsRef: RefObject<PartInfo[]>;
  onParts: (parts: PartSummary[]) => void;
}) {
  useLayoutEffect(() => {
    const root = rootRef.current;
    if (!root) return;
    const parts = collectParts(root);
    partsRef.current = parts;
    onParts(parts.map(({ id, name }) => ({ id, name })));
    return () => {
      for (const p of parts) {
        p.mesh.position.copy(p.base);
        setHighlight(p.mesh, false);
      }
      partsRef.current = [];
    };
  }, [rootRef, partsRef, onParts]);
  return null;
}

const deg = THREE.MathUtils.degToRad;
const tmpA = new THREE.Vector3(), tmpB = new THREE.Vector3();

/** Vị trí mỗi linh kiện = gốc + offset bung (hệ root) + offset cầm (mặt phẳng màn hình, đơn vị world). */
function applyParts(parts: PartInfo[], t: Transform, highlight: string | null) {
  for (const p of parts) {
    const off = explodeOffset(p.center, p.modelCenter, t.explode);
    const a = p.root.localToWorld(tmpA.copy(p.center));
    const b = p.root.localToWorld(tmpB.set(p.center.x + off.x, p.center.y + off.y, p.center.z + off.z));
    const grab = t.partOffsets[p.id];
    if (grab) b.add(new THREE.Vector3(grab.x, grab.y, 0));
    const parent = p.mesh.parent;
    if (!parent) continue;
    parent.worldToLocal(a);
    parent.worldToLocal(b);
    p.mesh.position.copy(p.base).add(b.sub(a));
    setHighlight(p.mesh, p.id === highlight);
  }
}

function Rig({ onFrame, partsRef, children }: { onFrame: FrameFn; partsRef: RefObject<PartInfo[]>; children: ReactNode }) {
  const ref = useRef<THREE.Group>(null);
  const camera = useThree((s) => s.camera);
  const raycaster = useMemo(() => new THREE.Raycaster(), []);
  const hitTest = useCallback<HitTest>(
    (x, y) => {
      const parts = partsRef.current;
      if (parts.length < 2) return null; // model liền một khối: không cầm linh kiện
      raycaster.setFromCamera(new THREE.Vector2(x * 2 - 1, -(y * 2 - 1)), camera);
      const hit = raycaster.intersectObjects(parts.map((p) => p.mesh), false)[0];
      return hit ? (parts.find((p) => p.mesh === hit.object)?.id ?? null) : null;
    },
    [camera, raycaster, partsRef],
  );
  useFrame((_, dt) => {
    const { transform: t, highlight } = onFrame(dt, hitTest);
    const g = ref.current;
    if (!g) return;
    // Ursina và three ngược chiều quay: đổi dấu để giữ đúng cảm giác như bản Python
    g.rotation.set(-deg(t.rotX), -deg(t.rotY), 0);
    g.position.set(t.x, t.y, 0);
    g.scale.setScalar(t.zoom);
    g.updateMatrixWorld(true);
    applyParts(partsRef.current, t, highlight);
  });
  return <group ref={ref}>{children}</group>;
}

type Props = {
  modelUrl: string | null;
  onFrame: FrameFn;
  onModelError: (e: Error) => void;
  onParts: (parts: PartSummary[]) => void;
};

export const Scene = memo(function Scene({ modelUrl, onFrame, onModelError, onParts }: Props) {
  const rootRef = useRef<THREE.Group>(null);
  const partsRef = useRef<PartInfo[]>([]);
  return (
    <Canvas camera={{ position: [0, 0, 20], fov: 40 }} dpr={[1, 2]}>
      <color attach="background" args={["#07090c"]} />
      <ambientLight intensity={0.6} />
      <directionalLight position={[5, 8, 10]} intensity={1.6} />
      <directionalLight position={[-6, -4, -8]} intensity={0.4} color="#3df5c4" />
      <Rig onFrame={onFrame} partsRef={partsRef}>
        <group ref={rootRef}>
          <ModelBoundary key={modelUrl ?? "demo"} onError={onModelError}>
            <Suspense fallback={null}>
              {modelUrl ? <GltfModel url={modelUrl} /> : <DemoRobot />}
              <PartsCollector rootRef={rootRef} partsRef={partsRef} onParts={onParts} />
            </Suspense>
          </ModelBoundary>
        </group>
      </Rig>
    </Canvas>
  );
});
```
