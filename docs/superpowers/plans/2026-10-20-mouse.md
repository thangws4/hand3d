# Điều khiển bằng chuột — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trong `/play`, điều khiển model bằng chuột/chạm một ngón (xoay, cầm linh kiện, dịch, zoom, hover tên linh kiện), thanh trượt "Độ bung", nút "Đặt lại"; dùng được ngay không cần bật camera.

**Architecture:** `Controller` thêm API chuột thuần (`pointerDown/Move/Up/Hover`, `clearHover`, `wheel`, `setExplode`) với trạng thái riêng (`pointerGrab`, `pointerHovered`) để bước xử lý tay không đè lên. `Player` bắt pointer events trên một lớp bọc `Scene`, dùng `hitTest` mới nhất nhận từ `onFrame`; thẻ "Bật camera" thu về góc, không che khung 3D.

**Tech Stack:** Next.js 16, React 19, R3F 9, Node 22 test runner.

**Spec:** `docs/superpowers/specs/2026-10-20-mouse-design.md`

## Global Constraints

- `web/lib/*.ts`: Node type stripping; `npm test` = `node --test "lib/**/*.test.ts"`.
- Độ nhạy dùng lại hằng số tay: xoay `ROT_SENS`, dịch và cầm `PAN_SENS`; lăn chuột `WHEEL_SENS = 0.0015`, `zoom × exp(−deltaY × WHEEL_SENS)` kẹp `[ZOOM_MIN, ZOOM_MAX]`; thanh trượt `0…EXPLODE_MAX`.
- Toạ độ chuột chuẩn hoá theo khung `/play` (0..1), cùng hệ con trỏ tay.
- Chuột trái/một ngón = `rotate` (bắt đầu trên linh kiện → cầm); chuột phải hoặc Shift + trái = `pan`.
- Highlight = `grabbed ?? pointerGrab ?? hovered ?? pointerHovered`.
- Lăn chuột không cuộn trang (listener `wheel` không passive, `preventDefault`); menu chuột phải bị chặn trên khung 3D; `touch-action: none`.
- Chữ tiếng Việt có dấu; không nhãn VIẾT HOA giãn chữ.

## Review Focus

- Đang cầm linh kiện bằng chuột mà camera đang chạy và không có tay → `step()` của tay không được thả linh kiện (test Task 1).
- Kéo thanh trượt độ bung trong lúc 2 tay đang xoè → giá trị mới thành mốc, không bị tay kéo ngược về (test Task 1: `setExplode` xoá mốc bung tay).
- Nhả chuột ngoài khung 3D / mất pointer (chuyển tab) → hết kéo, không dính (pointer capture + `pointercancel`; test Task 1 `pointerUp`).
- Rê chuột rời khung → linh kiện thôi sáng (`clearHover`, test Task 1).
- Lăn chuột trên khung không cuộn trang (e2e Task 2).

e) Sau `reset()`, thêm các hàm:
```ts
  pointerDown(x: number, y: number, mode: PointerMode, hitTest: HitTest = () => null): void {
    const hit = mode === "rotate" ? hitTest(x, y) : null;
    this.pointerGrab = hit;
    this.#pointer = { mode: hit ? "grab" : mode, x, y };
  }

  pointerMove(x: number, y: number): void {
    const p = this.#pointer;
    if (!p) return;
    const dx = x - p.x, dy = y - p.y;
    const t = this.transform;
    if (p.mode === "grab" && this.pointerGrab) {
      const o = t.partOffsets[this.pointerGrab] ?? { x: 0, y: 0 };
      t.partOffsets[this.pointerGrab] = { x: o.x + dx * PAN_SENS, y: o.y - dy * PAN_SENS };
    } else if (p.mode === "rotate") {
      t.rotY -= dx * ROT_SENS;
      t.rotX -= dy * ROT_SENS;
    } else if (p.mode === "pan") {
      t.x += dx * PAN_SENS;
      t.y -= dy * PAN_SENS;
    }
    p.x = x;
    p.y = y;
  }

  pointerUp(): void {
    this.#pointer = null;
    this.pointerGrab = null;
  }

  /** Rê chuột (không kéo): linh kiện dưới chuột; đang kéo thì giữ nguyên. */
  pointerHover(x: number, y: number, hitTest: HitTest = () => null): void {
    if (!this.#pointer) this.pointerHovered = hitTest(x, y);
  }

  clearHover(): void {
    this.pointerHovered = null;
  }

  wheel(deltaY: number): void {
    const t = this.transform;
    t.zoom = clamp(t.zoom * Math.exp(-deltaY * WHEEL_SENS), ZOOM_MIN, ZOOM_MAX);
  }

  /** Thanh trượt độ bung; xoá mốc của 2 tay để nếu tay đang xoè thì lấy giá trị này làm mốc mới. */
  setExplode(v: number): void {
    this.transform.explode = clamp(v, 0, EXPLODE_MAX);
    this.#explodeStart = null;
  }
```

```tsx
  const onFrame = useCallback(
    (dt: number, hitTest: HitTest) => {
      hitTestRef.current = hitTest;
      const hands = handsRef.current;
      const gestures = controller.step(hands, dt, hitTest);
      const highlight = controller.grabbed ?? controller.pointerGrab ?? controller.hovered ?? controller.pointerHovered;
      const name = highlight ? (partNames.current.get(highlight) ?? "") : "";
      if (name !== partLabelRef.current) {
        partLabelRef.current = name;
        setPartLabel(name);
      }
      const text = hands.map((h, i) => `${h.side}: ${gestures[i]}`).join(" | ") || "Không thấy tay";
      if (text !== hudRef.current) {
        hudRef.current = text;
        setHud(text);
      }
      // Con trỏ tay và thanh trượt cập nhật trực tiếp trên DOM mỗi khung, không qua React state
      const el = cursorRef.current;
      const c = controller.cursor;
      if (el && el.parentElement) {
        el.style.display = c ? "block" : "none";
        if (c) el.style.transform = `translate(${c.x * el.parentElement.clientWidth}px, ${c.y * el.parentElement.clientHeight}px)`;
      }
      const s = sliderRef.current;
      if (s && document.activeElement !== s) s.value = String(controller.transform.explode);
      return { transform: controller.transform, highlight };
```

- [ ] **Step 3: Thêm xử lý chuột (sau `onDrop`)**

```tsx
  const toStage = (e: { clientX: number; clientY: number }) => {
    const r = stageRef.current?.getBoundingClientRect();
    return r ? { x: (e.clientX - r.left) / r.width, y: (e.clientY - r.top) / r.height } : { x: 0, y: 0 };
  };

  const onPointerDown = (e: ReactPointerEvent<HTMLDivElement>) => {
    const mode: PointerMode = e.button === 2 || e.shiftKey ? "pan" : "rotate";
    if (e.button !== 0 && e.button !== 2) return;
    e.currentTarget.setPointerCapture(e.pointerId); // nhả chuột ngoài khung vẫn kết thúc kéo
    const p = toStage(e);
    controller.pointerDown(p.x, p.y, mode, hitTestRef.current);
  };

  const onPointerMove = (e: ReactPointerEvent<HTMLDivElement>) => {
    const p = toStage(e);
    controller.pointerMove(p.x, p.y);
    if (e.pointerType === "mouse") controller.pointerHover(p.x, p.y, hitTestRef.current);
  };

  const onPointerEnd = () => controller.pointerUp();

  // Lăn chuột: listener không passive để chặn cuộn trang (onWheel của React là passive)
  useEffect(() => {
    const el = stageRef.current;
    if (!el) return;
    const onWheel = (e: WheelEvent) => {
      e.preventDefault();
      controller.wheel(e.deltaY);
    };
    el.addEventListener("wheel", onWheel, { passive: false });
    return () => el.removeEventListener("wheel", onWheel);
  }, [controller]);
```
